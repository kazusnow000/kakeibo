# Simple家計簿

ブラウザ内の `localStorage` に記録を保存する、オフライン対応のシンプルな家計簿です。

## PWAとして使う

- iPhone/iPadのSafariでは、共有メニューから「ホーム画面に追加」を選ぶと専用アイコンで追加できます。
- 初回表示後は、アプリ本体とアイコンが端末に保存され、通信できない状態でも起動できます。
- 新しい版が公開された場合は、次回オンラインで開いたときに新しい本体を取得します。表示中の操作を中断しないよう、画面遷移・再起動時に反映されます。

## データについて

PWA化では、既存の以下の `localStorage` キーと保存形式を変更していません。

- `kakeibo:records:<YYYY-MM>`
- `kakeibo:months-index`
- `kakeibo:fixed`

記録は端末とブラウザごとに保存されます。定期的にアプリ内のJSONバックアップを書き出してください。
